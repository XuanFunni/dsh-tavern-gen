# dsh-tavern-gen

给 DSH Tavern **卡片工作台**用的生图插件。

和正文自动配图不同，这套是「先商量再出图」：你在对话里说想画什么，Agent 去查人物库、按世界书规则写出英文提示词，翻译成中文逐项念给你听，你点头之后它才调用生图渠道。图片以 Markdown 图片语法回到回复里，可以直接插进正文。

主要用在角色卡制作、试画风、试提示词这些场景——一张一张调，不靠运气。

## 和其他插件的分工

| 插件 | 用在哪 | 谁触发 |
|---|---|---|
| `dsh-tavern-image` | 游玩模式（story / script） | 模型在正文里写标记，插件自动配图 |
| `dsh-tavern-gen`（本插件） | 卡片工作台（card） | Agent 主动调用工具，用户确认后出图 |

两者互不抢活：本插件注册的工具都用 `tavern.toolModes({ modes: ['card'] })` 锁在卡片工作台，游玩模式里根本看不到。

## 安装

把整个目录放进 Tavern 的插件目录：

```
<DSH 数据目录>/tavern/data/plugins/dsh-tavern-gen/
```

然后重启 DSH。浏览器侧要强刷一次（`client.js` 带 `Cache-Control: immutable`，普通刷新会继续吃旧缓存）。

装好之后在「设置 → 卡片生图」里能看到面板。

## 第一次配置

### 云端渠道

1. 打开「设置 → 卡片生图 → 配置」。
2. 后端选「云端」，点「新增渠道」，选 provider（NovelAI 兼容站、OpenAI Images、Gemini、Atlas Cloud 等）。
3. 填地址、模型、鉴权方式，粘贴 API Key。
4. 点「保存并测试连接」。

API Key 交给宿主的凭据服务保管，明文不落盘、不出宿主。设置页里只能看到「已配置」，看不到密钥本身。

### 本地 ComfyUI

后端切「本地」，填 `http://127.0.0.1:8188`，点测试连接。然后导入一张 **API 格式**的工作流 JSON（ComfyUI 界面里「保存（API格式）」导出的那种，不是普通工作流）：

- 导入后会写进 `workflows/`，并自动识别提示词节点、负面节点、尺寸节点、步数、CFG、采样器、种子。
- 勾上「锁定」之后，再导入不会顶掉当前默认。
- 没有工作流时本地出图会直接报错，不会退回简易模式。

**种子**：ComfyUI 网页里的「生成后控制」（`control_after_generate`）不会写进导出的 API JSON，里面只有一个固定值。插件不接管的话，同一提示词永远出同一张图，ComfyUI 还会直接返回上次的缓存。所以种子由插件按设置页的选择自己算：

| 选项 | 行为 |
|---|---|
| `randomize`（默认） | 每张抽新种子 |
| `fixed` | 沿用上一次出图的种子，从 randomize 切过来就是重现刚看到的那张 |
| `increment` / `decrement` | 上一次的种子加一 / 减一 |

上一次的种子按工作流文件名记在数据目录的 `seed-state.json`，不进 `config.json`。`gen_image` 对应两个参数：`seed` 指定第一张的种子（复现某张图用），`seed_control` 只对这一次调用换控制方式、不改设置。

### 尺寸与出图节奏

`gen_image` 的 `size` 只有三档：竖图、横图、方图。本地 ComfyUI 下不填时用工作流里识别出的宽高；工作流用连线节点给宽高（比如 `ResolutionSelector`）时插件解析不出数字，尺寸由工作流决定，返回里也这么写，不会编一个默认值。云端渠道不填时用渠道配置里存的宽高，再没有就回竖图。

想要别的比例、或者想改默认尺寸，直接在对话里说，让 Agent 改渠道配置——不用翻设置页。

一次出几张用 `count` 参数（1–4 张）；同时跑几个任务看配置里的 `imageConcurrency`。这两项同样可以在对话里让 Agent 调。`count` 是串行循环，不是并发。

### 图片链接

部分 Android 宿主不能在对话里显示相对图片链接。插件会按以下顺序选择图片链接的来源地址，出图返回和画廊使用同一规则：

1. `config.json` 的 `publicOrigin`，例如 `"https://tavern.example.com"`。
2. 最近一次插件接口或图片请求学到的地址，保存到数据目录 `image-cache/dsh-tavern-gen/origin.json`，启动时同步读回。优先读取 `X-Forwarded-Host` / `X-Forwarded-Proto`，否则使用 `Host` 和连接的 HTTP / HTTPS 协议；代理头有多个值时取第一项。
3. 宿主的 `webServer.host` 和 `webServer.port` 推导出的 HTTP 监听地址。通配监听地址转换为本机回环地址，不固定端口；监听信息尚未就绪时会在出图前重试。
4. 都拿不到时保留相对路径，兼容旧行为。

`publicOrigin` 默认留空，旧配置缺少这个字段也能正常使用。没有历史记录、不打开设置页时，第一张图也可使用监听地址；从局域网或反向代理访问时，应先打开设置页或设置固定地址。图片请求同样可以更新学习地址，地址变化才异步写盘，写盘失败不影响请求。

多端交替访问时，使用最近的有效接口或图片请求地址。已保存的学习地址优先于监听地址，因此保留旧记录后更换端口，首次出图仍可能使用旧端口；打开设置页等新请求会刷新地址，也可删除 `origin.json` 后重启以重新使用监听地址。固定外部访问地址请设置 `publicOrigin`。

固定地址只填 `http://主机:端口` 或 `https://域名`，末尾 `/` 可省略，不带路径、用户名、密码、查询参数或 token；无效值会退回自动识别。手动改文件后重启插件生效。反向代理应覆盖客户端传入的转发头，或配置固定的 `publicOrigin`。

## 设置页

面板顶部有一个「启用工具」开关。关掉后卡片工作台的 Agent 看不到本插件的工具——不能出图，也查不到人物库、服装库和画风配置；已经生成的图和画廊记录不受影响，随时能再打开。默认开启，旧配置升级过来也是开启。改完立刻生效，不用重启。

- **配置**：渠道表单，云端 / 本地切换，画风预设，采样参数。
- **世界书**：按分册管规则，保存后自动生成 skill 读的参考文件。
- **画风预设**：卡片式增删改，点圆点选当前生效那套。预设负责拼画师串和负面词。
- **人物库**：按角色维护外观 traits，正面 / 背面 / 常规 / 细节各分开。
- **服装库**：每套七块（上身、下身、鞋、配饰、整套兜底、背影补充、负面）。
- **画廊**：出图记录，按出图会话分组，点组标题收起展开；能一键复制回提示词。

### 本局画廊

出的图也会出现在游玩界面的画廊里，那里有一行标作「本局生图」。

**按会话隔离**：只有本局出过的图才列出来，别的会话生的不会串进来。

那一块的排版和分组由 Tavern 前端决定，插件只负责递数据——带来源的条目在宿主那里固定成一整行。本插件从浏览器侧补了两条外观：图片行铺成网格换行、来源名显示成「本局生图」。这是改宿主渲染出来的 DOM，不是宿主提供的接口能力。

## 工具

| 工具 | 扣费 | 作用 |
|---|---|---|
| `gen_image` | 真实扣费 | 提交出图，返回可写进回复的图片链接 |
| `read_character` | 免费 | 查人物库，不传名字列全部，传名字取外观 traits |
| `read_outfit` | 免费 | 查服装库 |
| `read_image_config` | 免费 | 查当前渠道、模型、画风预设、可选尺寸 |
| `find_prompt` | 免费 | 按词查素材表，只回命中的几条 |

`gen_image` 的参数：`prompt`（必填）、`negative`、`channel`、`size`、`count`、`preset`、`sampler`，以及两个只对本地 ComfyUI 生效的 `seed`、`seed_control`。`channel`、`preset`、`seed_control` 是单次覆盖，不写回全局配置。

返回里每张图给三样：能直接写进回复的 Markdown 图片语法、裸链接（给人复制用）、磁盘绝对路径。路径只是备查，图出来直接贴进回复就行，不要求读图核验；只在需要看画面细节时才读那个文件。

## 世界书与规则

`worldbook.json` 按「分册 → 条目」两级组织，每个条目保存后生成一份 md 到 `skills/image-prompt/references/<分册>/<条目>.md`，同时写一份 `references/INDEX.md`，记录当前每个文件的档位、路径和标题。Agent 先读索引再按档位取文件，不靠文件名点名，也不用自己列目录——加了条目索引会跟着重写，不需要改任何提示词。

自带的 `always` 档规则够写日常图。条目上的 `mode` 决定它什么时候被读：

| mode | 含义 |
|---|---|
| `always` | 任何题材都读 |
| `nsfw` / `gore` | 按题材加读 |
| `lookup` | 按段检索，不通读 |
| `manual` | 改库时读 |
| `prescan` | 提交前扫 |

要加自己的规则，新建条目写就行，档位选对即可——标了 `always` 的，模型写图前会自动读到，不用改 SKILL.md。同一档可以放多条，模型会全部读完；分册里条目变多，读取次数也会跟着变。

## 素材表

`find_prompt` 查的是世界书里的「素材表」分册，**默认留空**，放你自己的提示词素材。

条目格式固定：

```
**中文名**
`tag1,tag2,tag3`
```

一条一个分类卡。工具按名字、tag 内容、分类名做子串匹配，不传 `query` 时返回分类索引。

## 已知限制

- **模型名只能在配置里改**，不进工具参数。换模型常常连带换协议，塞进参数只会让模型乱填。
- **工作流模式会整段替换负面节点**，预设里的负面词和工具 `negative` 都会被顶掉。
- **画廊删除会连图片文件一起删**，删了找不回来。
- 人物库、服装库、世界书都是 JSON 直存，不是并发安全的。不要在多个标签页同时编辑同一个库。
- **种子状态跟着工作流文件名走，存在数据目录**。删了 `image-cache/dsh-tavern-gen/seed-state.json` 就从头开始；换机器、重装插件之后 `fixed` 拿不到上次那张图。
- 模型生成质量受生图模型、提示词、种子、LoRA 影响，人物库只能约束外观描述，不保证每张图完全一致。
